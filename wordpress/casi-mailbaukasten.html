Mail-Baukasten

Mails im Gestaltungssystem der CASI bauen und direkt über den CASI-Server verschicken – genau so, wie sie hier aussehen, auch auf dem Handy. Dazu die E-Mail-Signatur.

Von Claude vorausgefüllt. Bitte alles prüfen, dann unten senden.

Apple Mail

Mail → Einstellungen → Signaturen → „+“ → Signatur einfügen. Den Haken „Immer meiner Standardschrift entsprechen“ entfernen.

Outlook (Mac, Windows, Web)

Einstellungen → Signaturen → Neue Signatur → einfügen → speichern.

Gmail

Einstellungen → Alle Einstellungen anzeigen → Signatur → Neu → einfügen → Änderungen speichern.

Apple Mail zeigt die CASI-Schriften; Gmail und Outlook setzen Helvetica – das ist so gewollt.
